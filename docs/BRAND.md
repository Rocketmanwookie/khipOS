# KHIP OS brand direction

## Name

**KHIP OS**, pronounced “kip.” KHIP connects the product name to the existing
human/device/agent protocol. The name is short enough for spoken commands,
terminal output, an application menu, and an OS boot screen.

## Mascot

**Kip** is the visible working partner: a compact industrial rover with small
capable hands, an expressive luminous display, and subtle controls-engineering
construction cues. Kip is competent and approachable, but not childish.

Required UI states:

- Idle: present, unobtrusive, microphone off
- Listening: mint audio arcs and an unmistakable active indicator
- Thinking: quiet animated processing expression
- Working: task and responsible specialist visible
- Approval required: amber only; no action implied before authorization
- Warning/error: distinct from approval and never communicated by color alone

## Mark

The mark combines a protected packet, linked agent nodes, and a subtle `K`.
It must remain recognizable at 16 px and work in monochrome. The generated
concept board is exploratory; a clean SVG construction is the next brand task.

## Palette

- Forest black: `#07110F`
- Panel green-black: `#0D1C19`
- Signal mint: `#76F7C2`
- Cool white: `#E7F7F1`
- Approval amber: `#FFD37A`

Amber is reserved for authorization and caution states.

## Voice

Direct, calm, technically literate, and transparent about uncertainty and
action state. Kip distinguishes “I planned,” “I prepared,” and “I executed.”
