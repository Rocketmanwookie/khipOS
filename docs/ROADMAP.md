# Roadmap

## Milestone 1 — Foundation (complete)

Acceptance: local shell runs; voice/text capture works where supported; six
specialists are visible; intents route deterministically; projects persist;
sensitive intents stop at approval; tests pass; architecture is documented.

## Milestone 2 — Useful coding partner

- Connect a configurable local or hosted language model
- Add sandboxed filesystem and terminal adapters
- Add repository/project explorer and diff review
- Implement approval grant/deny and action receipts
- Replace JSONL indexes with SQLite while retaining packet export

## Milestone 3 — Desktop integration

- Package as a full-screen Wayland desktop session
- Global push-to-talk and movable compact assistant card
- Window and application context adapters
- Notifications, calendar/project queue, and downtime learning cards

## Milestone 4 — Productivity specialists

- Documents and spreadsheets
- Browser research and controlled web actions
- FreeCAD controls-engineering workbench bridge
- Plugin manifest, permission review, and versioned tool contracts

## Milestone 5 — Installable KHIP OS

- Reproducible live ISO based on a pinned Ubuntu LTS release
- UEFI/Secure Boot validation and installer integration
- Dual-boot installation guide, recovery media, rollback, and updates
- Hardware compatibility matrix and release signing

## Milestone 6 — Bounded autonomy

- Scheduled and background work with explicit budgets
- Persistent specialist teams and independent validation
- PSUDO hardware prototype
- Measured reliability, privacy, and failure-recovery criteria
